CodePen Homepage Replica



Proyecto final del curso Coding Foundations – HTML \& CSS



Este proyecto consiste en replicar la página principal de CodePen.io, enfocándose en:



Estructura HTML semántica



Diseño con CSS moderno



Construcción de navbar



Manejo de imágenes



Botones, estilos y layout responsive



Aproximación fiel a un diseño profesional



&nbsp;Requerimientos cumplidos

&nbsp;Navbar



Incluye exactamente los elementos solicitados:

Pens, Projects, Posts, Collections, Spark (▾), Create (▾), Log In, Sign Up



&nbsp;Imágenes



Se utiliza la imagen oficial del logo CodePen y la captura del editor proporcionada por el curso.



&nbsp;Estilos y diseño



El layout replica la estructura original:



Título principal



Subtexto



Botones



Imagen a la derecha



Footer con 4 secciones (Teams, Education, Privacy, Writing)



&nbsp;Runtime



El código funciona sin errores.



&nbsp;Precisión visual



La recreación se acerca al diseño del ejemplo proporcionado.
